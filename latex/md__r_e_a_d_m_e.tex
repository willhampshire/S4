Conda package created due to platform independence.
\begin{DoxyItemize}
\item Create new conda environment using {\ttfamily conda create -\/n s4-\/venv-\/name python=3.\+12} (3.\+10 to 3.\+12 available)
\item {\ttfamily conda activate s4-\/venv-\/name}
\item {\ttfamily conda install -\/c willhampshire s4}
\end{DoxyItemize}

Install in a new environment to avoid incompatabilities as above. Refer to {\ttfamily marcus-\/o}\textquotesingle{}s \href{https://github.com/marcus-o/S4}{\texttt{repo}} for more info.\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Manual local installation}{Manual local installation}}\label{md__r_e_a_d_m_e_autotoc_md2}

The Makefile will need paths adjusting -\/ I only adjusted the conda recipe.\hypertarget{md__r_e_a_d_m_e_autotoc_md3}{}\doxysection{\texorpdfstring{Developer Build Instructions}{Developer Build Instructions}}\label{md__r_e_a_d_m_e_autotoc_md3}

Install Visual Studio developer tools to access {\ttfamily nmake}, {\ttfamily cl} and {\ttfamily lib}. Create {\ttfamily conda create -\/n "{}build-\/env"{} python=3.\+12}. Activate build-\/env. Requires {\ttfamily conda install} of\+:
\begin{DoxyItemize}
\item {\ttfamily boost}
\item {\ttfamily boost-\/cpp} from default channel (gets static .lib called libboost\+\_\+serialization.\+lib)
\item {\ttfamily libarchive} from conda-\/forge channel
\item {\ttfamily setuptools}
\item {\ttfamily wheel}
\item {\ttfamily suitesparse}
\item {\ttfamily conda-\/build}
\end{DoxyItemize}

Configure VS build tools file location in {\ttfamily build.\+bat}, if using different version. Run the commands in the build script manually to check filepaths and tools are installed. Verify valid contents of .lib files using {\ttfamily lib /\+LIST \texorpdfstring{$<$}{<}.lib file\texorpdfstring{$>$}{>}}, where to use lib, build tools must be activated (open Developer Command Prompt or run the {\ttfamily vcvars\+\_\+\+\_\+} file manually).
